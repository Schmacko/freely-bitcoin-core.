# Superseded FREELY protocol parameter proposal

**Status:** Superseded on 18 November 2026 by the owner-approved protocol baseline.

The earlier proposal values in this file are historical and are not the approved FREELY configuration. In particular, its former message magic, ports, address prefixes, genesis script and PoW-limit proposal must not be used.

The authoritative exact values, security implications, deterministic vectors and implementation gates are maintained in [FREELY (FLY) approved protocol parameter baseline](FREELY-APPROVED-PROTOCOL-PARAMETERS.md).

Approval authorizes implementation and verification only. It does not activate production parameters, authorize public RPC/P2P exposure, DNS seeds, mining deployment, testnet/mainnet launch or release. The genesis nonce and final block hash remain derived outputs that must be independently generated and verified.

The superseded proposal remains available in repository history for auditability.
